Architectural Principles

🧬
Seed-Derived Entropy
Every delay, task order, keystroke interval, and session window derives deterministically from the installation and account seed. Zero shared constants exist across accounts, preventing behavioral clustering.
⚡
Pure Go • Zero Driver Overhead
No Node, npm, cgo, or Selenium webdrivers. Compiles to a single static binary running on low-resource Azure B1s (1 vCPU, 1GB RAM) nodes with minimal CPU and memory footprints.
🖥️
Real Display over Xvfb
Refuses detection-vulnerable --headless flags. Operates an authentic Chromium window under a virtual X11 framebuffer with integrated private noVNC streaming for live human oversight.
🛡️
Zero-CAPTCHA Safety Engine
Permanently out of scope: solving CAPTCHAs or bypassing risk flags. On detection of any safety signal, Macro R records the telemetry and safely enters risk pauses to protect account standing.
☁️
Multi-Tenant Azure Cloud Mesh
Automated CLI provisioner that deploys dedicated Azure VMs per friend/account. Fronted by a salted SHA-256 reverse proxy gateway that isolates environments completely.
📈
Progressive Warm-Up
New accounts gradually scale search point targets over a multi-day ramp schedule, mimicking natural human onboarding patterns rather than hitting daily maximums immediately.
📰
Read to Earn (MSN Automation)
Automates MSN / Microsoft Start article reading points with organic dwell times, human-like scroll wheel steps, and natural reading delays that credit daily news bonuses.
🔔
Operator Notification Engine
Instantly notifies the user via webhooks/alerts on streak milestones, daily points completed, or immediately halts and alerts if any safety risk or CAPTCHA signal appears.

Clean-Room Design Pattern

// Clean-room seed-derived pacing: all browser-observable pauses derive from account seed
type PaceController struct {
    accountSeed [32]byte
    entropyPRNG *rand.Rand
}

// Zero shared constants ensure no two Macro R installations exhibit matching timing
func (p *PaceController) KeystrokeDelay() time.Duration {
    base := p.entropyPRNG.Float64()*45.0 + 35.0 // 35ms - 80ms human variance
    return time.Duration(base) * time.Millisecond
}
